# SpeedMaxx — website & client portal

Modern landing page and demo client portal for **SpeedMaxx Digital Networks** (ISP, Shirdi · Shrirampur · Kopargaon · Rahata · Loni).

- **Website** — `index.html`: dark/light theme, network-themed animations (GSAP, Lenis), plans & pricing, coverage map, plan finder.
- **Client portal** — `client/index.html`: app-style dashboard (data usage charts, router & Wi-Fi settings, plans & bills, support). Mobile layout uses a bottom tab bar.

> The client portal is a **front-end demo with sample data** — no real accounts or payments.

Static site, no build step. Open `index.html` in a browser, or serve the folder with any static server.
Libraries load from CDNs (GSAP, Lenis, Vanilla-Tilt, Chart.js).
